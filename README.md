# Homelab Monitoring System

**Полноценная система мониторинга и управления домашней сетью через Telegram.**

Этот проект — готовая лабораторная среда для изучения сетевых технологий, безопасности и автоматизации. Он включает в себя:
- VLAN-сегментацию с L3-маршрутизацией
- DNS-фильтрацию (Pi-hole + Unbound)
- Многофункционального Telegram-бота для мониторинга и удалённого управления
- Автоматический сбор метрик с роутера через headless-браузер

## 🎯 Возможности

- **Обнаружение устройств** в VLAN 10, 20, 30 (ARP-мониторинг) и в сети роутера (Nmap).
- **SSH-атаки** — алерты при брутфорсе (5+ попыток за 60 секунд).
- **Pi-hole статистика** — количество запросов, процент блокировки, топ-5 заблокированных доменов.
- **Метрики роутера** — количество клиентов, WAN IP, статус Wi-Fi, SSID, uptime.
- **Интернет-мониторинг** — проверка доступности 8.8.8.8.
- **Контроль диска** — предупреждение при <10% свободного места.
- **Обновления** — уведомление о доступных пакетах apt.
- **Fail2Ban** — оповещение о новых блокировках IP.
- **Удалённое управление** — перезагрузка, обновление системы, создание бэкапов (с подтверждением).

## ⚙️ Технологии

- Python 3 (requests, Playwright, nmap)
- Docker / Docker Compose
- Raspberry Pi OS + Arch Linux
- Pi-hole, Unbound, WireGuard
- VLAN, L3-маршрутизация
